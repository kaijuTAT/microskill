# Question Templates

## Mini Review Pack

Use when the user asks for quick review:

1. 5 quick facts.
2. 5 flashcards.
3. 3 choice questions.
4. 2 fill-in questions.
5. 1 short answer or calculation question.
6. Answer key with brief explanations.

## Chapter Practice Pack

Use when the user asks for one chapter:

- 10 choice questions.
- 5 fill-in questions.
- 3 short answer questions.
- 2 calculation or programming questions.
- Answer key and common mistakes.

## Mock Exam Pack

Use when the user asks for a mock paper:

- 20 choice questions.
- 10 fill-in questions.
- 5 short answer questions.
- 2 assembly programming questions.
- 3 interface-chip questions across 8259, 8253, and 8255.
- Total score and answer key.

## Assembly Programming Template

```text
题目: 给定 DATA 段中的数组/变量，编写 8086 汇编程序完成指定处理。
要求: 初始化 DS；结果存入指定变量或寄存器；程序正常返回 DOS。
考点: 数据定义、循环、条件转移、寄存器选择、DOS 调用。
答案: 给出完整代码，并解释关键 3 行。
```

## 8259 Template

```text
题目: 某系统使用 8259 管理外部中断，已知中断类型号基址和请求线。
要求: 求中断类型号，写出初始化或屏蔽命令，说明响应流程。
考点: ICW/OCW、IRR/IMR/ISR、优先级、EOI。
```

## 8253 Template

```text
题目: 已知 CLK 频率和目标输出频率/延时，使用某计数器和某模式。
要求: 计算初值，写控制字，写初始化程序片段。
考点: 计数初值、控制字、LSB/MSB、方式 0/2/3。
```

## 8255 Template

```text
题目: 按要求设置 A/B/C 口输入输出方向或控制 PC 某一位。
要求: 写控制字和 OUT 指令，说明每一位含义。
考点: 方式选择字、C 口置位/复位、方式 0/1/2。
```
